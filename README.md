# Architectural Portfolio Studio

Website Builder Prompt — Personal Creative Portfolio

Create a premium, modern personal portfolio website for a multidisciplinary creative professional specializing in Architecture, Graphic Design, and Video/Content Creation.

The website should feel like a combination of a modern architectural studio, architectural blueprint, and high-end creative portfolio. Avoid the typical colorful freelancer portfolio aesthetic. The overall experience should be minimal, sophisticated, structured, editorial, and visually intentional.

Core Design Direction

The visual concept should be inspired by:

Modern minimalist architecture

Contemporary houses

Architectural blueprints

Technical drawings

Architectural grids

Editorial design

Premium creative studios

High-end portfolio websites

Think of the website as a digital architectural presentation board.

Use a strong grid system, generous whitespace, precise alignment, thin technical lines, subtle measurement/grid details, and clean typography.

The design should feel:

Minimal

Modern

Premium

Professional

Technical

Creative

Sophisticated

Calm and confident

Do not make it look overly futuristic, overly flashy, or like a generic developer portfolio.

Color Palette

Use a primarily monochromatic palette:

Black — primary background / strong sections

White — primary text and light sections

Gray — secondary text, borders, blueprint lines, supporting UI

Gold — very subtle accent color

Suggested visual balance:

70% black / white

25% gray

5% gold accent

Gold should be used sparingly for things such as:

Hover states

Small labels

Section numbers

Active navigation indicators

Fine decorative lines

Important CTAs

Small architectural annotation details

Avoid large gold backgrounds or excessive gold elements.

Typography

Use a clean modern sans-serif typeface for the primary UI and body text.

Typography should have strong hierarchy:

Large editorial headings

Small uppercase technical labels

Clean body copy

Wide letter spacing for navigation and category labels

Consider combining:

Modern Sans Serif + subtle technical/architectural typography

For example:

Large bold headings

Small uppercase labels such as ARCHITECTURE / 01

Monospaced or technical typography for small metadata if appropriate

Do not use overly decorative fonts.

Portfolio Structure

The portfolio should have three primary creative disciplines:

01 — Architecture

Create a dedicated Architecture Portfolio page.

This page should showcase architectural work in a clean editorial/gallery format.

The page should contain two primary sections:

Architectural Detail Samples

Showcase architectural detail drawings, technical drawings, construction details, plans, sections, elevations, or other architectural documentation.

Use a grid-based gallery.

Each project/sample should support:

Image

Title

Short description

Category

Optional year

Optional software/tools

The gallery should feel like an architecture firm's project archive.

Architectural Projects

Create a separate project showcase for larger architectural projects.

Use large visual cards or editorial project layouts.

Each project can include:

Project name

Project type

Location

Year

Short description

Multiple images

Architectural drawings

Plans

Sections

Renderings

When opening a project, use a detailed project page with a case-study presentation.

The project page should feel similar to an architectural presentation board.

02 — Graphics

Create a dedicated Graphics & Illustrations Portfolio page.

The main overview of this section should prominently feature the existing:

Graphics & Illustrations Portfolio — Jervin Habagat.pdf

Treat this PDF as an important portfolio presentation.

Provide a visually prominent way to view the PDF, preferably through:

Embedded PDF viewer

Preview/cover

Open portfolio button

Do not simply hide the PDF behind a generic download link.

The Graphics page should also contain these categories:

Black Rose Content Creators

Showcase graphic/content work created for Black Rose Content Creators.

Use a visual gallery that emphasizes the actual artwork.

Include:

Social media graphics

Promotional materials

Branding/content assets

Event graphics

Other relevant designs

GFX Samples

Create a dedicated gallery for graphic design samples.

Use a masonry/grid presentation where appropriate.

Thumbnail Design

Create a dedicated section showcasing YouTube/video thumbnail designs.

Thumbnails should be displayed large enough to evaluate the design quality.

Use hover interactions that reveal:

Project name

Type

Brief description

Keep animations subtle and fast.

Layout

Use a desktop-first responsive design.

Desktop:

Wide content areas

Strong asymmetric grids

Large imagery

Generous whitespace

Editorial layouts

Two-column and three-column sections

Mobile:

Single-column layouts

Large readable typography

Touch-friendly navigation

Proper image cropping

Horizontally scrollable galleries where appropriate

Overall UX Goal

The website should feel like entering a modern architectural studio's digital portfolio.

The first impression should communicate:

"This person is precise, creative, professional, and capable of working across multiple creative disciplines."

Prioritize the portfolio work over decorative elements.

Use the architectural/blueprint aesthetic as a design system, not as a theme that overwhelms the content.

The final result should look appropriate for:

Architecture firms

Creative agencies

Design studios

Freelance clients

Companies hiring full-time creative professionals

The website should feel premium enough for professional clients while still showing personality and creativity.
